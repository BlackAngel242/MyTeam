# Noms de versions

Chaque version de MyTeam porte le nom d'une divinité ashanti ou yoruba, choisi par l'auteur du projet. Le numéro reste la référence technique ; le nom donne un esprit à la version.

| Version | Nom | Divinité | Esprit de la version |
|---|---|---|---|
| 0.4.2 | Ọṣun | Yoruba : les eaux douces, la beauté, l'abondance | Le flux de travail rendu visible : autonomie, santé du bureau, capsule animée |
| 0.5.0 | Ṣàngó | Yoruba : le tonnerre, la justice | Ce qui attend une décision humaine est signalé clairement, et la décision reste à DrSmoke |

Pour la suite, l'auteur décide. Quelques noms possibles, à titre de propositions seulement : Anansi (ashanti, les histoires), Nyame (ashanti, le ciel), Asase Yaa (ashanti, la terre), Èṣù (yoruba, le messager), Ọbàtálá (yoruba, la création), Ọ̀rúnmìlà (yoruba, la sagesse), Oya (yoruba, les vents et les transitions).
