# Noms de versions

Chaque version de MyTeam porte le nom d'une divinité ashanti ou yoruba, choisi par l'auteur du projet. Le numéro (0.4.2) reste la référence technique ; le nom donne un esprit à la version.

| Version | Nom | Divinité | Esprit de la version |
|---|---|---|---|
| 0.4.2 | Ogun | Yoruba : le fer, les outils, le chemin ouvert | Outillage et solidité : santé du bureau, tests, protocole d'équipe |

Pour la suite, l'auteur décide. Quelques noms possibles, à titre de propositions seulement : Anansi (ashanti, les histoires), Nyame (ashanti, le ciel), Asase Yaa (ashanti, la terre), Èṣù (yoruba, le messager), Ṣàngó (yoruba, le tonnerre), Ọ̀ṣun (yoruba, l'eau douce), Ọbàtálá (yoruba, la création), Ọ̀rúnmìlà (yoruba, la sagesse).
