# Plan de travail

Ce modèle décrit le travail du projet choisi. Avant d'ajouter des tâches, confirmer que ce dossier peut être partagé publiquement. Les données de session, chemins personnels, crédits, clés et journaux de travail restent dans le stockage local privé.

## À planifier

- [ ] Définir un objectif vérifiable et le dossier du projet.
- [ ] Attribuer un responsable à chaque tâche et préciser les fichiers concernés.
- [ ] Vérifier les changements et les contrôles avant de cocher une tâche.

Le chef met à jour les cases après vérification. Chaque personne conserve ses notes privées hors du dépôt partagé.
